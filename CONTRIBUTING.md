# Contributing to TenantWall

Thanks for your interest! Here is how you can help.

## Ways to Contribute

- Report bugs
- Suggest features
- Improve documentation
- Submit pull requests

## Setup

### Prerequisites
- Java 21+
- Python 3.11+
- Maven 3.9+

### Clone

```bash
git clone https://github.com/maksoud13/tenantwall.git
cd tenantwall
```
Java Agent
bash
cd java-agent
mvn clean install
Python Parser
bash
cd python-parser
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
Development Workflow
Fork the repo

Create a feature branch

Make your changes

Test your changes

Open a Pull Request

Commit Convention
Add: — New feature

Fix: — Bug fix

Docs: — Documentation

Refactor: — Code refactoring
